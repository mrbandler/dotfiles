# CLI Tools Selection

Full list of CLI tools, TUIs, and apps to integrate into the Nix configuration.

## Navigation & Search
- [x] zoxide — smart cd with frecency
- [x] fzf/tv — fuzzy finder
- [x] fd — fast find replacement
- [x] ripgrep — fast grep replacement
- [x] yazi — terminal file manager

## File Viewers
- [x] bat — cat with syntax highlighting
- [x] eza — modern ls replacement

## Git Tools
- [x] delta — git pager with syntax highlighting
- [x] gh — GitHub CLI
- [x] gh-dash — GitHub dashboard TUI extension
- [x] enhance — GitHub Actions TUI (gh-dash companion)
- [x] diffnav — git diff navigator
- [x] git-cliff — changelog generator

## System Monitoring
- [x] btop — system monitor
- [x] kmon — kernel module monitor

## Container & Dev Tools
- [x] lazydocker — Docker TUI
- [x] lazyjj — Jujutsu VCS TUI
- [x] k9s — Kubernetes TUI

## JSON
- [x] jnv — interactive JSON filter using jq

## Process Management
- [x] process-compose — scheduler/orchestrator for non-containerized apps

## Journaling & Notes
- [x] jrnl — command line journal application
- [x] zk — Zettelkasten plain text note-taking assistant
- [x] nb — command line note-taking and knowledge base

## Disk & File Utils
- [x] ncdu — interactive disk usage TUI

- [x] trashy — safe rm replacement (FreeDesktop trash)

- [x] sd — sed replacement
